## Projetos em Destaque

### [Logáli](https://github.com/guiijelmito/Logali)
Rede social web para compartilhamento de experiências sobre lugares e estabelecimentos — projeto final da disciplina de Programação Web.
- **Frontend:** React + Vite, React Router, Axios, React Hook Form + Yup
- **Backend:** Node.js + Express, bcryptjs para autenticação

### [Portfólio](https://github.com/AqueleCaio/portifolio)
Site de portfólio pessoal, reunindo projetos, experiências e formas de contato.

### [CEDUC – Centro de Educação UNIFEI](https://ceduc.unifei.edu.br/)
Portal institucional da UNIFEI, com pipeline de dados WordPress → Elementor via plugin PHP customizado (`ceduc-data-bridge.php`), cache com transients e sistema de navegação acessível por teclado.
- **Stack:** PHP, WordPress (CPTs), JavaScript, Elementor
